FluxHelper 2.7.2 (БЕТА) — что нового
====================================

◆ ФИКС: УВЕДОМЛЕНИЯ НА ПК МОГЛИ МОЛЧА НЕ ПОКАЗЫВАТЬСЯ
  • Причина: обрезка текста уведомления не добавляла терминатор
    строки (wcsncpy) — Windows получал мусор в конце и не
    показывал всплывашку. Теперь текст гарантированно корректен.

◆ НОВОЕ: САМОЗАЖИВЛЕНИЕ РАСПИСАНИЯ СПОВЕЩЕНИЙ
  • Хост сам запрашивает расклад у интерфейса после загрузки
    страницы (notifReq), а интерфейс повторяет отправку каждую
    минуту — расписание уведомлений больше не может «потеряться».

◆ ДИАГНОСТИКА: хост подтверждает (notifAck), сколько уроков
  принято — видно в консоли интерфейса.

FluxHelper 2.7.1 — что нового
==============================

◆ НОВОЕ: КАНАЛЫ ОБНОВЛЕНИЙ — RELEASE И BETA
  • На GitHub теперь versions/release/<версия> и versions/beta/<версия>.
  • Обычные пользователи получают только релизы (как и раньше).
  • Админ/Разработчик может включить «Бета-обновления» в настройках
    (карточка «Акаунт») — тогда приложение предлагает и беты тоже,
    побеждает самая большая версия из двух каналов.

◆ НОВОЕ: ПЕРЕКЛЮЧАТЕЛЬ «БЕТА-ОБНОВЛЕНИЯ» (ПК и телефон)
  • Настройки -> Акаунт -> «Бета-обновления». Виден только
    Админу и Разработчику, обычным пользователям его нет.

◆ ФИКС: СКАЧИВАНИЕ APK НА ТЕЛЕФОНЕ
  • Первым проверяется правильное имя файла (FluxHelper_v<версия>.apk),
    затем запасные имена; добавлен канал release и GitHub Release
    как последний запасной источник.

◆ БАЗА: ВСЁ ИЗ 2.4.1 + ФУНКЦИОНАЛ 2.7.0
  • Вход через Google, вкладка «Акаунт», синхронизация через
    Cloudflare D1, уведомления ПК (трей + всплывашки), новый
    интерфейс, самостоятельная установка WebView2.

FluxHelper 2.7.0 — что нового
==============================

◆ ФИКС: ПОСЛЕ ВХОДА ВКЛАДКИ НЕ ПЕРЕКЛЮЧАЛИСЬ (ПК и телефон)
  • Причина: за окном входа открывался мастер групп, и его тёмная
    подложка «съедала» все нажатия — клики по «Налаштування»,
    «Акаунт» и вкладкам дней ничего не делали.
  • Теперь мастер групп открывается ТОЛЬКО после входа и только
    если группы ещё не выбраны. После входа сразу показывается
    расклад; если группы пришли из синхронизации — мастер сам закрывается.

◆ ВЕРНУЛИ ИКОНКИ ВКЛАДОК (ПК)
  • В переключателе «Розклад | Налаштування» снова иконки
    (календарь и шестерёнка), как в меню на телефоне.

◆ ФИКС: УВЕДОМЛЕНИЯ НА ПК НЕ ПРИХОДИЛИ
  • Исправлено переполнение в тексте уведомления Windows.
  • Иконка в трее теперь восстанавливается сама (после перезапуска
    проводника и при неудачном старте) — раньше без неё уведомления
    молча не показывались.
  • ЗАКРЫТИЕ ОКНА -> программа СВОРАЧИВАЕТСЯ В ТРЕЙ и продолжает
    напоминать об уроках (телефон будит AlarmManager, поэтому на
    нём работало, а на ПК программа должна быть запущена).
    Открыть — клик по иконке в трее; выйти — правый клик -> «Вийти».
  • Проверить уведомления: Настройки -> Режим разработчика ->
    «Надіслати тестове сповіщення». Если Windows всё равно глотает
    их — включи уведомления для FluxHelper в настройках Windows
    (Параметры -> Система -> Уведомления).

◆ АККАУНТЫ / СИНХРОНИЗАЦИЯ / СТАТИСТИКА -> CLOUDFLARE
  • Аккаунты, роли, синхронизация и статистика переехали из Firebase
    в облачную базу Cloudflare (D1) через собственный API
    (fluxhelper.pages.dev/api). Firebase теперь хранит ТОЛЬКО
    расклад (предметы, учителя, Zoom-ссылки) и обновления.
  • Вход работает по-прежнему: сайт проверяет одноразовый код
    (теперь и через новый API, и через запасной канал — надёжнее).
  • Синхронизация обновляется каждые ~20 секунд.

  • У «Мистецтва» пока нет ссылки — добавим, когда появится Zoom.
