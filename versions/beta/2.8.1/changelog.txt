FluxHelper 2.8.1 (beta) — что нового
=====================================

ИСПРАВЛЕН ВХОД (главное)
+ Вход снова работает! Причина поломки: Google удалил OAuth-клиент
  программы (Error 401: deleted_client) — из-за этого никто не мог
  войти ни с ПК, ни с телефона
+ Теперь вход — как в старых версиях: нажимаешь «Увійти через Google»,
  открывается твой сайт (fluxhelper.pages.dev) в браузере, входишь
  через Google там — и программа входит АВТОМАТИЧЕСКИ
+ Никаких системных окон «открыть приложение?» и разрешений — профиль
  передаётся мгновенно по локальному каналу (127.0.0.1), а если он
  заблокирован — срабатывает резервный канал (Firebase)

ОКНО АВТОРИЗАЦИИ
+ Исправлен критичный баг: на экране входа пропадали кнопки окна
  («Згорнути»/«Закрити»), окно нельзя было перетаскивать и клики
  по кнопкам не работали — теперь всё на месте на любом экране
+ Кнопки окна есть на ВСЕХ экранах и во ВСЕХ вкладках
+ Логотип больше не дублируется: если логотип уже показан по центру
  (экран входа, загрузка) — в панели его нет; на остальных вкладках
  лого и название — вверху слева, как обычно
+ Окно можно перетаскивать за фон ЛЮБОЙ вкладки (розклад, налаштування,
  акаунт, экран входа), а не только за самую верхнюю полоску

ВЕРХНЯЯ ПАНЕЛЬ
+ Убрано разделение (линия) между верхней панелью и содержимым —
  панель «растворяется» в фоне программы
+ Кнопки «Згорнути»/«Закрити» — без рамки, просто иконки; при наведении
  появляется лёгкая подсвеченная рамочка (у «Закрити» — красная)

ИКОНКИ ПРЕДМЕТОВ
+ Полностью новый набор красивых белых 2D-иконок в едином стиле:
  физкультура — бегущий человек, алгебра — большая Σ, география —
  глобус, украинский язык — книга, литература — раскрытая книга,
  химия — колба с жидкостью, информатика — монитор с </>, история —
  здание с колоннами, искусство — палитра, музыка — нота и т.д.
+ Новые иконки работают даже для предметов, приходящих из облака

Мелкое
+ Экраны «обновление» и «нет интернета» тоже не перекрывают панель окна
+ Тест ключей/токенов: рабочие — GitHub PAT (оба репозитория) и
  Cloudflare-токен №1; запасной Cloudflare-токен №2 оказался недействительным
