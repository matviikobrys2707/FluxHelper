FluxHelper 3.5.48 — что нового
==============================

СРОЧНОЕ (телефон)
+ Исправлен крах запуска программы на телефоне (java.lang.VerifyError в
  Notifs.calcAlarm — «if-eq/if-ne argument type mismatch (Conflict vs
  BooleanConstant)»): метод переписан с нуля на чистом байт-коде, проверено
  165 888 вариантов поведения — работает точь-в-точь как раньше, но больше
  не отбраковывается верификатором Android.

АВТОРИЗАЦИЯ НА САЙТЕ (главное)
+ Ошибка «__AUTH_ERR_» больше не появляется: в код сайта случайно попала
  заглушка, которая показывала фейковую ошибку входа при каждом открытии —
  удалена. Вход через Google теперь проходит чисто.
+ Экран входа больше нельзя обойти: если ты не вошёл в акаунт — расписание
  НЕ показывается вообще (ни при загрузке, ни при ошибках сети, ни после
  перезагрузки страницы). Показ — только когда акаунт подтверждён и данные
  загружены без ошибок.
+ Если данные акаунта загрузить не удалось, а локальной копии нет — лоадер
  не «выкидывает» в пустое расписание: программа тихо догоняет базу в фоне
  (до ~35 секунд), и только если совсем не получилось — показывает экран
  входа с понятной ошибкой «Не вдалося завантажити дані акаунта».
+ Загрузчик сайта (страница «визначаємо пристрій…») больше не зависает на
  85% из-за «мертвого» соединения: у каждого запроса жёсткий таймаут 4 с —
  страница быстро перезапрашивается и открывается.

СИНХРОНИЗАЦИЯ (телефон и сайт)
+ «Захожу в акаунт — просит налаштувати групи / данные не синхронизируются,
  помогает только перезапуск» — исправлено:
  • первая синхронизация после входа стала терпеливой (три попытки + фоновые
    догоняющие запросы до ~35 с вместо 9 секунд «один раз и хватит»);
  • при неудачной первой синхронизации группы больше НЕ СТИРАЮТСЯ и мастер
    настройки групп не открывается (он только для реально пустого акаунта);
  • когда база ответит — расклад, тема и налаштування прилетают сами, без
    перезапуска программы;
  • вкладка адміністратора и роль подгружаются с запасными попытками (раньше
    при холодном сервере можно было остаться «юзером» до перезапуска);
  • исправлен сбой (p.rs при пустых settings в строке акаунта), который
    молча убивал синхронизацию до перезапуска.
+ Серверные запросы синхронизации получили увеличенный таймаут (12 с) —
  холодный Cloudflare/D1 больше не срывает первый вход.

ПК
+ Версия сборки синхронизирована до 3.5.48 (интерфейс ПК не менялся — он
  работал; правило «APK и EXE выходят вместе» соблюдено).
