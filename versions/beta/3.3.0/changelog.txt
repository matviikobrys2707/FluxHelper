FluxHelper 3.3.0 — повернення до бази 2.9.2 + адмін-панель з 3.2.0
============================================================

БАЗА
* Уся програма знову побудована на архітектурі 2.9.2 (перевірена,
  стабільна): UI-файли розпаковуються на диск, база читається прямим
  запитом, нативні мости — тільки запасні. Код 3.х «захисту» повністю
  викинуто.

НОВЕ (ПК)
* Екран входу ПЕРЕРОБЛЕНО — тепер точно такий, як на телефоні:
  без картки-рамки, контент по центру на темному фоні.
* ВИПРАВЛЕНО «вгорі немає кнопок і лого»: титульна панель (лого +
  FluxHelper + Згорнути/Закрити) ТЕПЕР ЗАВЖДИ видима на екрані входу —
  гейт починається ПІД панеллю і фізично не може її перекрити.
* OAuth-клієнт оновлено на живий web-клієнт сайту входу (старий було
  видалено з Google Cloud — 401 deleted_client).

НОВЕ (ПК + ТЕЛЕФОН) — АДМІН-ПАНЕЛЬ (повний порт з 3.2.0)
* Нова вкладка «Адмін» (видима лише для ролі admin/developer з бази):
  - Розклад: додання/редагування/видалення/переставляння уроків,
    підтвердження видалення, вибір предметів і груп;
  - Zoom і вчителі: посилання Zoom для обох груп, ПІБ вчителів,
    автоматичне створення підсумку;
  - Іконки: вибір іконки для кожного предмета з пікера (113 іконок,
    категорії);
  - Тижні: чергування онлайн/офлайн-тижнів, кнопка «Поміняти»
    (weeks/flips у базі), великий календар.
* Усі зміни адмінки одразу пишуться в базу — пристрої класу
  підхоплюють їх у реальному часі.
* +71 нова іконка предметів (набір 3.2.0).

ТЕХНІЧНЕ
* ПК: статична лінковка (без libc++.dll / libunwind.dll) — запуск на
  будь-якій Windows 10/11 без сторонніх DLL.
* Android: база APK — 2.9.2 (versionCode 30300); ключ підпису той
  самий, що в 3.2.1/3.2.2 -> оновлення поверх без перевстановлення.
* Стабільний канал (release) залишається на 2.4.2.

ПК: FluxHelper.exe — один файл, без встановлення. ~1.8 МБ.
Android: versionCode 30300 (versionName 3.3.0).
