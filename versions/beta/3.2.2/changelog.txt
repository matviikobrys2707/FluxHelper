FluxHelper 3.2.2 — фікс запуску на ПК (DLL)
============================================================

ВИПРАВЛЕНО (ГОЛОВНЕ)
* ПК: виправлено помилку «The code execution cannot proceed because
  libc++-.dll / libunwind.dll was not found» — через неї 3.2.1 взагалі
  не запускався на Windows. Ці дві бібліотеки тепер ВБУДОВАНО в exe
  (статична лінковка), тож програма залежить лише від системних DLL
  Windows 10/11. Як і раніше: один файл, без встановлення.
* Телефон: функціональних змін немає — 3.2.1 уже містила фікс бази.
  Оновлення до 3.2.2 звичайне, БЕЗ перевстановлення (ключ підпису
  той самий, що у 3.2.1).

ТЕХНІЧНЕ
* libc++ / libunwind зібрано статично (замість динамічних llvm-mingw).
* Розмір exe зріс до ~1.7 МБ — це платою за незалежність від сторонніх DLL.
* Усі можливості 3.2.1 працюють як раніше: адмін-панель «Редагування
  розкладу», рамка «Тижні» з великим календарем, підтвердження видалення
  уроку, прямий доступ до бази (архітектура 2.8.0), оновлювач із
  перевіркою SHA-256.
* Стабільний канал (release) залишається на 2.4.2.

ПК: FluxHelper.exe — один файл, без встановлення. ~1.7 МБ.
Android: versionCode 30202 (versionName 3.2.2).
