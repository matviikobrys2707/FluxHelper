🔍 ДИАГНОСТИЧЕСКАЯ СБОРКА для случая «Заходимо в акаунт…» и ничего не происходит.

Логика входа остаётся ДОСЛОВНОЙ из 3.5.1 (как в 3.5.66). Что добавлено:

📱 ТОСТЫ-ШАГИ (видны поверх всего, не зависят от WebView):
   FH 1: login start        — кнопка дошла до Java, вход запущен
   FH 2: CM handle OK       — Credential Manager запущен по подготовленному хендлу
   FH 2: CM cold OK         — Credential Manager запущен холодным запросом
   FH 2: CM exception       — вызов CM упал с исключением
   FH 3: picker opened      — системный выбор аккаунта открыт
   FH 4: browser login      — браузерный вход открыт
   FH 4: browser FAILED     — браузер НЕ открылся (нет браузера?)
   FH 5: token received     — токен Google получен, идёт обмен
   FH 6: CM error <имя>     — имя ошибки Credential Manager (главное для диагноза!)

🔧 ПРОЧЕЕ:
   • Host.login / Host.loginLast: убран молчаливый catchall (как в 3.5.1!) —
     если Java падает, JS покажет «Не вдалося відкрити вхід» вместо вечного
     «Заходимо»; при этом сам вызов обёрнут в try в JS
   • Java-сторож 12с → 10с (браузерный резерв приходит раньше)
