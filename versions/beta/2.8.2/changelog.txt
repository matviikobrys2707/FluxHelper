FluxHelper 2.8.2 (beta) — что нового
=====================================

ТЕЛЕФОН: ВХОД ПОЛНОСТЬЮ ПЕРЕДЕЛАН (главное)
+ Вход больше НЕ перекидывает в браузер! Нажимаешь «Увійти через Google» —
  внизу открывается родная плашка Google со списком твоих аккаунтов
  (как в ChatGPT и monobank), выбираешь аккаунт — и ВСЁ, ты в программе
+ Программа больше не убивается в фоне: браузер больше не нужен.
  Профиль передаётся прямо внутри приложения через Google-токен
+ Если система всё же открыла браузер (запасной путь) — процесс программы
  теперь держит специальный сервис, и вход доводится до конца автоматически
+ Если приложение всё-таки закрыли во время входа — после запуска оно
  само продолжит ожидание подтверждения (ничего не теряется)
+ Вернулась модель телефона в реестр устройств (в 2.8.1 она потерялась)

ТЕЛЕФОН: ИНТЕРФЕЙС
+ Больше НЕТ вспышки интерфейса при запуске: пока не ясно, авторизован
  ли ты — показывается только загрузка; сразу после неё — либо программа
  (если вход уже был), либо экран входа. Основной интерфейс до входа
  не показывается НИ ОДНОГО кадра
+ Текст больше нельзя выделить и скопировать долгим нажатием (как на ПК)

КОМПЬЮТЕР
+ Окно входа теперь полноценное: иконка + название FluxHelper слева вверху,
  кнопки «Згорнути»/«Закрити» справа, окно можно перетаскивать
+ Окно входа стало компактнее и ниже: убраны пустые промежутки между
  логотипом, кнопкой Google и подписью версии
+ Анти-вспышка: пока программа не поняла, авторизован ли ты, показывается
  только загрузка — основной интерфейс не мигает

БАЗА ДАННЫХ (Cloudflare) — ЧИНИМО «НИФИГА НЕ РАБОТАЕТ»
+ Найдена причина пустой вкладки Users: на части ПК нативный канал базы
  молча не работал (прокси/фаервол), хотя вход и интернет были живы
+ Теперь данные юзеров пишутся ТРЕМЯ путями сразу: прямо из программы
  при входе, из интерфейса, и через Firebase-зеркало, которое доехает
  до Cloudflare, как только канал оживёт (даже через несколько часов)
+ Настройки акаунта (user_settings) теперь тоже сохраняются в Cloudflare
+ Запасной канал сети (WinINet — тот же стек, что у Edge) для ПК,
  где WinHTTP блокируется прокси/антивирусом

FIREBASE AUTHENTICATION
+ После входа через Google ты теперь появляешься во вкладке Firebase
  Authentication -> Users автоматически (и снова после удаления — при
  следующем входе). Раньше это работало только на странице сайта

ИКОНКИ ПРЕДМЕТОВ
+ Алгебра — новая жирная Σ (была тонкой и выбивалась из стиля),
  физика — атом с более чёткими орбитами; весь набор теперь единый

САЙТ
+ Иконка во вкладке браузера и на сайте — теперь ОРИГИНАЛЬНАЯ иконка
  приложения (обнови страницу Ctrl+F5, если видна старая)
+ Страница входа на сайте стала компактнее
