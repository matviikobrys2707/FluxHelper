FluxHelper 3.5.28 (бета) — 27.10.2026
=====================================

✦ БАЗА ДАНИХ У ХМАРІ НАВЕДЕНА ДО ЛАДУ
  • У кожного предмета тепер рівно стільки вчителів і Zoom-посилань, скільки треба:
    предмети з поділом на групи — Teacher 1 і Teacher 2 + Zoom 1 і Zoom 2
    (у технологій групи називаються «Дівчата» / «Хлопці»);
    предмети БЕЗ поділу — один учитель і одне посилання, жодних зайвих колонок.
  • Складено зайві колонки з бази (колишні Teacher/Zoom 0 — тепер чисті пари 1/2).
  • Таблиця розкладу в базі йде строго по порядку днів тижня: Пн → Вт → Ср → Чт → Пт.
  • Легасі-таблиці з Cloudflare D1 видалено повністю — міграцію звірено 1-в-1,
    дані збережені без втрат (архів копії знято перед видаленням).

✦ ВХІД ЧЕРЕЗ GOOGLE — «НЕЗЛАМНИЙ»
  • Сторінка входу в браузері після успішного входу показує КОД (6 знаків).
  • Якщо програма не підтягнула профіль сама (заблокований попап, холодний
    сервер, обірваний інтернет) — в програмі натисни «є код зі сайту?»,
    введи код — і вхід завершиться за секунду.
  • Якщо браузер заблокував вікно Google — тепер з'являється підказка,
    замість мовчазної нульової реакції.
  • Передача профілю в програму тепер іде одночасно ЧОТИРМА каналами —
    хоча б один дістане завжди.
