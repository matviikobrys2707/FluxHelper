3.5.22 — оновлення для твоєї версії (список фільтрується сам):
  САЙТ (усі версії — iPhone/Android і Windows/Mac):
    ✦ ОДИН URL ДЛЯ ВСЬОГО САЙТУ (просив власник: «убери все URL типа
      /iphone/ и /mac/ — чтобы был один URL»): тепер єдиний адрес —
      fluxhelper.pages.dev/main. Сторінка САМА визначає, хто ти:
      • телефон (сенсорний екран + малий екран) -> мобільна версія,
      • комп'ютер, ПЛАНШЕТ та будь-який великий екран (де все вміщується)
        -> версія для комп'ютера,
      і відкриває потрібну версію ПРЯМО в /main — адреса в рядку більше
      НІКОЛИ не змінюється. Старі адреси /iphone/... і /mac/... більше
      не окремі сторінки: прямий вхід на них миттю веде на /main
      (хеш вкладки зберігається: /mac/#settings -> /main#settings).
    / ФІКС: при перезавантаженні сторінки більше НЕ блимають старі
      іконки уроків (просив власник: «при перезагрузке на секунду
      появляются старые иконки»). Причина: легкий запит розкладу
      затирає «предмети» (а разом з ними адмінські іконки) у кеші, тож
      щоразу спершу малювалися вбудовані іконки, а після відповіді
      мережі вони «стрибали» на актуальні. Тепер кеш зберігається
      ЦІЛІСТЬЮ (усі вузли зливаються) + перемалювання взагалі не
      відбувається, якщо дані не змінилися.
    + Налаштування: «Запуск Zoom» (Додаток / Браузер) — ТЕПЕР НА САЙТІ
      для будь-якої версії (просив власник: «почему убрала? Это должно
      быть»): якщо вибрано «Додаток» — урок відкриває Zoom-посилання
      звичайно (підхоплює програма Zoom), якщо «Браузер» — відкривається
      веб-версія Zoom прямо в браузері (спеціальне посилання
      app.zoom.us/wc/...). Вибір синхронізується між пристроями.
    / Кнопка «Приєднатися» на картці уроку — тепер ТІЛЬКИ в застосунках
      Android і Windows (просив власник: «убери кнопку на сайте, пусть
      будет только в програмах»). На сайті урок відкривається тапом по
      самій картці (з підтвердженням, якщо воно ввімкнене).
    / ФІКС «прозорих» карток на телефоні (просив власник: «деякі уроки
      мають рамку темнішу, деякі світлішу»): причина — Safari іноді
      «замикає» картку на проміжній прозорості анімації появи. Анімація
      тепер гарантовано завершується (через 1.6 с картка стає
      фінально-непрозорою незалежно від примх браузера).
  WINDOWS (застосунок):
    + «Автоматичний вхід у Zoom» — ПОВНІСТЮ ПЕРЕРОБЛЕНО (власник:
      «оно просто открывает Zoom, даже не открывает ссылку… вообще
      ничего как будто не делает»):
      • причиною був НЕПРАВИЛЬНИЙ протокол запуску: виходило
        zoommtg://us05web.zoom.us/j/<id> — такого шляху Zoom не
        розуміє, тому відкривався «просто Zoom» без конференції. Тепер
        програма сама будує правильне глибоке посилання
        zoommtg://<хост>/join?action=join&confno=<id>&pwd=<pwd> і
        відкриває КОНФЕРЕНЦІЮ ще з C++ — гарантовано, навіть якщо
        автоматизація впаде;
      • якщо Zoom не відреагував — за 25 с сам відкриває твоє
        посилання через браузер (як людина), Zoom підхоплює зустріч;
      • автоматизація чекає ВІКНО ПІДКЛЮЧЕННЯ (те, де можна
        протестувати звук), зачиняє зайве вікно Zoom Workplace,
        ВИМКАЄ мікрофон і камеру (якщо ті увімкнені) і НАТИСКАЄ
        «Подключиться» / «Приєднатися» / «Увійти» — російська,
        українська та англійська версії Zoom;
      • три рівні натискання: UI Automation -> перемикач -> справжній
        клік мишею по кнопці;
      • повний лог дій: %TEMP%\fh_zoom_autojoin.log (діагностика:
        powershell -ExecutionPolicy Bypass -File
        %TEMP%\fh_zoom_autojoin.ps1 -List).
  АНДРОІД (застосунок):
