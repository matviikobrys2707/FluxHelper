FluxHelper 2.2.1

+ АВТОРИЗАЦІЯ ОБОВ'ЯЗКОВА: без входу через Google програма не починає роботу — екран входу завжди на місці, кнопки «Продовжити без авторизації» більше немає
+ НОВИЙ Client ID Google зашитий у код (тип «Настільний додаток») — помилка «Доступ заблоковано: запит цього додатка недійсний» виправлена; окремий клієнт для Android не потрібен
+ КЛЮЧІ В КОДІ: поля «OAuth Client ID» і «Cloudflare Account ID» у вкладці Розробника видалено — усе працює саме, налаштовувати нічого не треба
+ ЕКРАН ВХОДУ БЕЗ ІНСТРУКЦІЙ: тільки плюшки й кнопка Google
+ ТОПБАР ПК: панель вища, картка акаунта стала вправо і більше НЕ перекриває вкладки «Розклад/Налаштування»
+ СВІТЛА ТЕМА: перемикачі мають чіткий фон без сірої обводки по краях, виправлено десятки дрібних елементів (поля, підписи, іконки, слайдер, плитки тем)
+ ТЕЛЕФОН: сповіщення тепер з'являється ПО ЦЕНТРУ екрана; у меню-шухляді рядок версії замінено красивою карткою акаунта (аватар, ім'я, пошта)
+ ОПТИМІЗАЦІЯ ПК: прибрано безконечні анімації вкладок, спрощено важкі тіні й блюр на дрібних елементах, оптимізовано зміну розміру вікна — лагає значно менше
+ CLOUDFLARE D1 (fluxcontrol) активна одразу: профілі, налаштування і пристрої живуть у хмарі; Firebase — тільки розклад і оновлення
+ APK тепер називається з версією: FluxHelper-2.2.1.apk
