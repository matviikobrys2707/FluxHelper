# Стабільний канал оновлень FluxHelper (release)

- `latest.json` — маніфест каналу для всіх звичайних користувачів; застосунки
  порівнюють md5/розмір і качають файл із папки своєї версії.
- `<версія>/` — архів стабільних збірок. Останній стабільний реліз: **3.5.1**.
- Бета-версії живуть у [versions/beta](../beta/). Коли бета визріває — її
  піднімають у release: маніфест `versions/release/latest.json` оновлюють,
  гілку `main` зливають у `site-release`.
