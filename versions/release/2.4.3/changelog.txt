FluxHelper 2.4.3 — міст-оновлювач: завантаження оновлень з GitHub Releases
========================================================================================================================

ЄДИНА ЗМІНА (все інше — байт-в-байт код 2.4.2, дизайн і логіка не чіпались):
* Оновлення тепер завантажується з GitHub Releases (остання РЕЛІЗНУТА версія),
  а не з папки versions/release:
  1) інтерфейс шукає файл оновлення спершу в versions/release/<v>/ (зворотна
     сумісність), потім на GitHub Releases (releases/download/v<latest>);
  2) хост сам дізнається актуальний тег останнього релізу через
     github.com/<repo>/releases/latest (302 -> Location -> vX.Y.Z, БЕЗ GitHub API
     і без rate-лімітів) і качає ассет саме звідти;
  3) перевірка версії всередині завантаженого exe (захист від відкату і від
     несвіжого білда) — збереглась; якщо тег релізу старіший за версію з бази —
     качається версія з бази (відкат неможливий);
  4) запасний канал raw versions/release/<v>/ залишено.
* Призначення: старі інсталяції 2.4.2 отримують 2.4.3 через звичайний канал,
  а далі 2.4.3 вміє оновлюватись напряму з GitHub Releases (наступні релізи
  публікуються туди).
* Версія 2.4.3 (versionCode 24201), підпис офіційний (SHA-1 6871F0 — той самий,
  що у 2.4.2, оновлення встановлюється поверх без видалення).
