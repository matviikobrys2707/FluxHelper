FluxHelper 2.3.5 — что нового
==============================

ГОЛОВНЕ: ВІКНО ОНОВЛЕННЯ БІЛЬШЕ НІКОЛИ НЕ «ГУБИТЬСЯ»
+ Знайдено причину, чому вікно оновлення могло не з'являтися, хоча нова
  версія на сервері вже була: застосунок перевіряв наявність файлу
  ТІЛЬКИ на одному адресі (raw-CDN GitHub). Якщо саме цей сервер лежав,
  був перевантажений або заблокований (так часто робить шкільний Wi-Fi),
  застосунок мовчки вирішував «файлу немає» і ховав оновлення
+ ТЕПЕР файл оновлення шукається ОДРАЗУ в 5 місцях: GitHub Releases
  (найнадійніше сховище, без CDN-кешу), raw-CDN і github.com/raw.
  Вікно «Доступне оновлення» з'явиться, якщо файл знайдено хоча б в
  ОДНОГО джерела — така ситуація більше не повториться
+ Перевірка версії теж стала трьохканальною: raw GitHub -> github.com ->
  Firebase. Кожен канал живе на окремих серверах, тож «не бачу оновлення»
  тепер можливо тільки коли інтернет відсутній повністю

НА ТЕЛЕФОНІ
+ Завантаження APK теж по черзі з 8 адрес (спочатку Releases, потім raw,
  потім github.com/raw) — якщо один канал недоступний, файл все одно
  завантажиться з іншого
+ Сам процес не змінився: вікно оновлення -> кнопка «Оновити» -> застосунок
  сам качає APK і сам відкриває встановлення. Жодних посилань у браузер

НА КОМП'ЮТЕРІ
+ Ті самі виправлення: вікно оновлення шукає exe у кількох місцях,
  завантаження йде по черзі з кількох джерел
+ Вхід через Google НЕ ЗМІНЕНО — працює так само, як у 2.3.3/2.3.4
