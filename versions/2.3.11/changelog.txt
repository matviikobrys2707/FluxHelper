FluxHelper 2.3.11 — что нового
==============================

АВТОРИЗАЦІЯ НА ПК (ГОЛОВНЕ)
+ Вікно «Потрібен вхід у FluxHelper» тепер на ВЕСЬ екран: поки не
  авторизуєшся через Google — користуватись програмою не можна
+ Кнопку «Продовжити без авторизації» ВИДАЛЕНО повністю
+ Escape і системна кнопка «Назад» більше не закривають вікно входу
+ Після виходу з акаунта екран входу відкривається одразу

ФІКС «ПАКЕТ НЕДІЙСНИЙ» (оновлення на телефоні)
+ Знайдено причину: коли GitHub-акаунт ховають, сервер віддає
  HTML-сторінку замість APK, і застосунок намагався її встановити
+ Тепер завантажений файл ПЕРЕВІРЯЄТЬСЯ: це має бути справжній APK
  (ZIP-магія + AndroidManifest.xml) з точним MD5 — биті/фальшиві
  файли відхиляються, а не ламають встановлення
+ Додано РЕЗЕРВНИЙ канал завантаження через хмару Firebase: оновлення
  працюють навіть коли GitHub недоступний або акаунт сховано

СИНХРОНІЗАЦІЯ / ІНШЕ
+ Усі системи перевірено: Firebase, Cloudflare D1, GitHub, вхід через
  Google на телефоні та ПК
+ Виправлено дрібні помилки компіляції внутрішньої збірки
