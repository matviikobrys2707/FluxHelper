FluxHelper 1.5.0

+ переробили систему оновлень: версія приїжджає з Firebase, файли — з GitHub
+ вікно оновлення зі списком змін, яке не можна закрити до встановлення
+ на ПК нова версія встановлюється сама: скачала, замінила, перезапустила
+ на телефоні оновлення встановлюється прямо з застосунку (один раз треба дозволити)
+ екран «Немає з'єднання», якщо інтернет недоступний — головний екран не показується
+ повернули оригінальну іконку: шапка, завантаження, меню, сплеш на телефоні
+ сповіщення про уроки на телефоні тепер запитуються одразу при запуску
- дрібні виправлення дизайну та швидкості
