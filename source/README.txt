====================================================================
  FluxHelper — ПАКЕТ РАЗРАБОТЧИКА (исходники + сборка + деплой)
  Автор приложения: Blazix
====================================================================

ЧТО ДЕЛАТЬ: запусти ОДИН файл — Build.bat (двойной клик).

    [1] ПОЛНЫЙ ДЕПЛОЙ — спросит версию и описание, соберёт EXE + APK
        и опубликует на GitHub + Firebase + Release
    [2] Собрать только EXE      -> prebuilt\FluxHelper.exe
    [3] Собрать только APK      -> prebuilt\FluxHelper.apk
    [4] Опубликовать уже собранные файлы (без сборки)
    [5] Только проверка (ничего не публикует)
    [0] Выход

ВАЖНО: Build.bat — текст только на английском (ascii). Это сделано
специально: bat-файлы с кириллицей ломаются на Windows из-за кодовых
страниц. Сообщения короткие и понятные, всё остальное объясняется здесь.

При первом запуске скрипт САМ скачает и распакует инструменты
в папку tools\ (один раз, ~300 МБ):
    - llvm-mingw      (компилятор C++ для EXE)
    - Java 17 Temurin (для сборки APK)
    - Android build-tools r34 + platform-33 (aapt2, d8, apksigner)
Всё остальное уже лежит в пакете: tools\webview2 (SDK), tools\ecj.jar
(компилятор Java), keys\fluxhelper.keystore (ключ подписи).
Ничего устанавливать в систему не нужно. Нужен только интернет.

--------------------------------------------------------------------
ВЕРСИИ
--------------------------------------------------------------------
Версию спрашивает скрипт. Enter = следующая (X.Y.Z + 0.0.1).
Версия записывается в src\version.h и apk\AndroidManifest.xml
(versionCode = major*1000 + minor*100 + patch, например 1.7.2 -> 1702).

--------------------------------------------------------------------
ЧТО ГДЕ ЛЕЖИТ
--------------------------------------------------------------------
Build.bat              — всё управление (меню)
src\main.cpp           — код окна (Win32 + WebView2)
src\ui_desktop.h       — ДИЗАЙН ДЛЯ ПК (HTML/CSS/JS, вшит в exe)
src\version.h          — версия и название (FluxHelper)
src\app.rc             — ресурсы: иконка + VERSIONINFO
src\logo.png           — логотип (иконка и сплеш делаются из него)
apk\assets\www\index.html — ДИЗАЙН ДЛЯ ТЕЛЕФОНА/ПЛАНШЕТА (HTML/CSS/JS)
apk\src\...            — java-код Android-приложения
apk\res\...            — ресурсы Android (иконки, сплеш)
deploy\deploy.ps1      — публикация на GitHub (вызывается из Build.bat)
prebuilt\              — собранные FluxHelper.exe / FluxHelper.apk (1.7.2)
keys\fluxhelper.keystore — ключ подписи APK (пароль: fluxhelper)
tools\ps\*.ps1         — вспомогательные скрипты (версия, сборка APK)

Не публикуй пакет целиком в открытый доступ:
в deploy\deploy.ps1 зашит GitHub-токен, а в keys\ — ключ подписи.
(В GitHub-репозитории лежит копия БЕЗ токена и БЕЗ ключа.)

--------------------------------------------------------------------
ДИЗАЙН: ДВА ОТДЕЛЬНЫХ ФАЙЛА, НАСТРОЙКИ РАЗНЫЕ
--------------------------------------------------------------------
ПК (src\ui_desktop.h):
  титульная панель с кнопками окна, масштаб под размер окна,
  горячие клавиши 1..5. Настройки — «виндоус-стиль»: широкие карточки
  в сетке, группы переключаются сегмент-кнопками [1-ша | 2-га] прямо
  на месте, без окон.
Телефон (apk\assets\www\index.html):
  кнопки дней на всю ширину, бургер-меню, свайпы между днями,
  большие кнопки. Настройки — «мобильный стиль»: большая градиентная
  шапка с логотипом, полноразмерные ряды 58px, группы открываются
  шторкой СНИЗУ экрана, большие переключатели и слайдер.
Оба файла — обычный HTML/CSS/JS: открой их в браузере, чтобы
посмотреть дизайн (плейсхолдеры подставляются при сборке).

--------------------------------------------------------------------
РЕЖИМ РАЗРАБОТНИКА (на телефоне и на ПК)
--------------------------------------------------------------------
Открой Настройки, прокрути в самый низ (блок «FluxHelper · версія»)
и нажми на ВЕРСИЮ 5 раз подряд -> появится окно «Увімкнути режим
розробника?». После включения в настройках появится жёлтая секция
«Режим розробника» с кнопкой «Надіслати тестове сповіщення» — она
присылает настоящее уведомление вида «Урок ... почнеться через N хв»
(на ПК — уведомление Windows, на телефоне — push-уведомление).
Выключить: кнопкой в той же секции или ещё 5 нажатий на версию.

--------------------------------------------------------------------
ИКОНКА / ЛОГОТИП
--------------------------------------------------------------------
Замени src\logo.png (квадратный PNG) — иконка exe и логотип сплеша
собираются из него. В src\build\logo.ico лежит готовая иконка;
если меняешь logo.png, перегенерируй .ico любым конвертером
PNG->ICO (несколько размеров: 16/32/48/256).

--------------------------------------------------------------------
APK И ОБНОВЛЕНИЯ НА ТЕЛЕФОНЕ (ОДИНАКОВЫЙ ИДЕНТИФИКАТОР)
--------------------------------------------------------------------
Ключ подписи: keys\fluxhelper.keystore (пароль: fluxhelper).
Package name: com.fluxhelper.app — один и тот же во всех версиях.
Версии 1.7.2+ подписаны ЭТИМ ключом — обновление ставится поверх
старого БЕЗ удаления (это и есть «одинаковый идентификатор»).
НЕ ТЕРЯЙ файл keys\! Если собрать с ДРУГИМ ключом — телефон
потребует удалить старое приложение (данные групп сбросятся).
Если у тебя стоит версия 1.7.1 или старее — удали её ОДИН раз,
поставь 1.7.2, и все следующие обновления будут ставиться сами.

--------------------------------------------------------------------
ЧТО ПРОИСХОДИТ ПРИ ДЕПЛОЕ ([1] или [4])
--------------------------------------------------------------------
deploy\deploy.ps1:
  1) находит собранные prebuilt\FluxHelper.exe / .apk
  2) публикует versions\<версия>\ на GitHub:
     FluxHelper.exe, FluxHelper.apk, changelog.txt
     + копии FluxControl.* / Blazix.* (для старых сборок)
  3) обновляет Firebase: update/latest = новая версия + описание
  4) создаёт GitHub Release v<версия> (постоянные ссылки:
     github.com/matviikobrys2707/FluxHelper/releases/latest/download/...)
  5) проверяет, что всё реально скачивается
Описание изменений вводится по-украински, несколько пунктов через |.
